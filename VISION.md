# Vision

This is a living document for the product's long-term vision, goals, and ideas.

## Product

Open-source personal finance software with two ways to use it:

- **Hosted service:** a managed version offered for a monthly subscription.
- **Self-hosted:** an open-source monorepo that anyone can fork and deploy with ease.

Both experiences are core to the product. Developer experience should receive as much design attention as user experience, including a straightforward path to getting started, understanding the codebase, and hosting a personal instance.
